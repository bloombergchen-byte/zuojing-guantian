# 网站图标素材来源

本目录供“坐井观天”网站图标使用。角色与网站标志是独立图层；字符均为用户选定的简化版草稿，不是原漫画截取。

## 角色

- `simple-lie.png`：露琪亚趴在标志上，来自项目 `work/character-icon-study` 的同名小样。
- `simple-lean.png`：露琪亚在标志旁倚靠，来自同名小样；这是用户选定的简化版，不是 `refined-lean.png`。
- `simple-hug.png`：露琪亚抱住标志，来自同名小样。

三张图以此前项目小样为参考，使用 OpenAI 内置图片生成工具制作；提示重点是黑白 Q 版露琪亚、简化手部和五官、透明背景、分别呈现趴住／倚靠／抱住，并为独立网站标志留出空间。项目内完整过程参见 `work/character-icon-study/问卷小样说明.md` 和 `图标方向-确认记录.md`。三张 PNG 均具有透明通道。人物形象指向《死神》中的朽木露琪亚，其相关权利不因此说明而改变。
